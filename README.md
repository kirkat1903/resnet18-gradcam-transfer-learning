# Image Classifier with Grad-CAM Explainability

Дообучение классификатора изображений (transfer learning на ResNet18) с
визуализацией Grad-CAM — тепловой картой, показывающей, на какие области
изображения модель опиралась при принятии решения.

## Почему это интереснее обычного классификатора

Любой может обучить ResNet на своих картинках. Explainability показывает
понимание того, *как* модель принимает решение — это важно для доверия
к модели и часто спрашивают на собеседованиях по ML/CV.

## Структура данных

Формат `torchvision.datasets.ImageFolder`:

```
data/
    train/
        class_a/
            img1.jpg
        class_b/
            img1.jpg
    val/
        class_a/
            img1.jpg
        class_b/
            img1.jpg
```

Можно использовать любой датасет: дефекты на изделиях, породы животных,
типы документов и т.д. — чем специфичнее и практичнее домен, тем сильнее
проект смотрится в портфолио.

## Установка

```bash
pip install -r requirements.txt
```

## Обучение

```bash
python train.py --data-dir ./data --epochs 15 --batch-size 32
```

Для маленьких датасетов (сотни изображений на класс) имеет смысл заморозить
backbone и обучать только последний слой:

```bash
python train.py --data-dir ./data --epochs 10 --freeze-backbone
```

Результат — файл `best_model.pt` с весами и списком классов.

## Визуализация Grad-CAM

```bash
python grad_cam.py --model best_model.pt --image test.jpg --output result.jpg
```

На выходе — изображение с наложенной тепловой картой (красный/жёлтый —
области, сильнее всего повлиявшие на предсказание) и подписью предсказанного
класса с уверенностью модели.

## Как работает Grad-CAM (кратко)

1. Прямой проход изображения через сеть, получаем предсказание.
2. Обратный проход (backward) от нужного класса до последнего свёрточного
   слоя (`layer4` у ResNet18) — получаем градиенты по картам признаков.
3. Усредняем градиенты по пространственным осям → вес важности для каждого
   канала признаков.
4. Взвешенная сумма карт признаков + ReLU → тепловая карта, где ярче —
   важнее для предсказания.

Источник метода: Selvaraju et al., "Grad-CAM: Visual Explanations from Deep
Networks via Gradient-based Localization" (2017).

## Возможные доработки

- Сравнение Grad-CAM для верного и неверного предсказания — наглядно
  показывает, когда модель "смотрит не туда"
- EfficientNet или ViT вместо ResNet (для ViT нужен другой вариант метода —
  Attention Rollout)
- Веб-демо на Streamlit/Gradio: загрузка своего фото → предсказание + тепловая карта
- Батчевая обработка целой папки изображений с сохранением сводного отчёта

## Метрики для резюме/портфолио

После обучения на своих данных впишите сюда:
- Accuracy / F1 на val-выборке
- Количество классов и размер датасета
- Пример, где Grad-CAM выявил, что модель ориентируется на нерелевантные
  признаки (это отличный кейс для рассказа на собеседовании)
